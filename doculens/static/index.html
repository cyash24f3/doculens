Extract→Chunk→Embed→Retrieve→Cite

Local search with a learned embedding model

DocuLens extracts text from digital PDFs, Markdown, and text files. Section-aware chunks preserve page and heading references. The local MiniLM sentence-transformer model produces normalized embeddings. Exact cosine search works alongside BM25 keyword ranking; hybrid search combines their top rankings through reciprocal-rank fusion.

Two answer modes, clearly labeled

Evidence mode displays verbatim excerpts from relevant passages. It works locally without an LLM key and does not claim to synthesize a complete answer. Generated mode sends the question and selected passages to an explicitly configured LLM endpoint. It validates returned source IDs, but this does not establish factual entailment. Generated claims still need review.

Questions the documents cannot answer

A relevance gate can abstain when no passage meets its threshold. The gate is a heuristic, not a proof that an answer exists. Similar but unanswerable questions can still retrieve plausible passages. The evaluation reports these failures rather than hiding them.

Sources, versions, and deletion

Replacing a document archives the prior version. Current-only retrieval excludes it; archived versions require explicit inclusion. Deleting a version removes its text, chunks, and vectors, and clears stored traces and evaluations that could retain excerpts. Other versions remain; deletion does not restore an older version automatically.

Privacy and provider setup

After the one-time embedding-model download, evidence mode runs locally. No document text is sent to an external model unless you select generated answers and configure a provider. An OpenAI-compatible endpoint can be local or remote; Amazon Bedrock is another supported option. The optional provider connection has to be configured in environment variables.

Limits worth understanding

There is no OCR or guaranteed reconstruction of PDF tables. The app supports at most 200 document versions and 10,000 chunks. It is a single-user local application without authentication or distributed workers. The sample policies describe a fictional Atlas service; they are evaluation material, not promises about this app’s features.

Reading the benchmark

The 66-question set has fixed development and test labels authored from the fictional corpus. It is not independently human-reviewed. Retrieval recall and MRR measure source discovery. Answer-term coverage is only a lexical proxy; verbatim quote fidelity is source membership, not answer correctness. Actual remote LLM quality is not tested by this local benchmark.

DOCUMENT LIFECYCLE

Replace the current version

The current version becomes archived. Its passages leave current-only search when the replacement is indexed successfully.

Delete this document version?

This removes the selected version and its index. Stored query traces and evaluation reports are also cleared to remove retained excerpts. Other versions remain archived.
