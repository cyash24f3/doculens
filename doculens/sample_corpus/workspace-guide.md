# Workspace guide

Fictional Atlas documentation for DocuLens evaluation. This is not a real service policy.

## Creating a workspace

A workspace keeps one team’s documents, members, and settings together. Workspace names must contain between 3 and 60 characters. New workspaces begin on the Sandbox plan and can contain up to 10 members.

## Supported files

The document library accepts PDF, Markdown, and UTF-8 plain text files. Each upload can be at most 10 MiB. Scanned PDFs require OCR before upload; the application does not perform OCR.

## Ownership transfer

Only the current owner can transfer workspace ownership. The new owner must already be an active workspace member. Ownership changes are recorded in the audit log.

## Leaving a workspace

A member can leave a workspace from Account settings. A workspace owner must transfer ownership before leaving. Leaving a workspace does not delete documents previously uploaded by that member.
